# TypeScript examples

- [Embedded task runner](task-runner/) — start a Mobilerun task from a
  server-side SDK client, watch the device live with `@mobilerun/react`, and
  render its status and structured result.
- [Branded assistant](branded-assistant/) — a white-label travel assistant with a
  persona, live progress, follow-up questions, structured result cards, and a
  per-user credit ledger kept by your own server.
